# 👴 BackInMyDay (`bimd`)

**Archéologie logicielle de l'ère IA** — Découvrez à quelle époque technologique votre code a été écrit.

```bash
pip install backinmyday
```

## Utilisation

```bash
# Scanner le dépôt courant
bimd scan

# Chercher une date ou un commit
bimd era 2023-03-15

# Générer un badge pour votre README
bimd badge
```

## Contribuer

La base de données des époques est dans `bimd/eras.yaml`. Les PR sont les bienvenues !

## Sources

Les dates de publication des modèles sont vérifiées grâce à la base de données [Epoch AI — Notable AI Models](https://epoch.ai/data/notable-ai-models) (3 500+ modèles avec dates de publication, organisations et métriques).

## Notes

- **Epoch AI** provides a comprehensive dataset of notable AI models with verified publication/release dates. Many early-era dates (pre-2023) are cross-referenced from this source.
- **OpenAI Changelog** is the authoritative source for all OpenAI model API release dates. Dates reflect when models became available via the API, not internal training completion dates.
- **Anthropic Newsroom** provides announcement dates for Claude models. The model ID suffix (e.g. `20251001`) is used as the release date when no explicit blog post exists.
- **Google Gemini API Docs** list available models but do not always include explicit release dates. Dates are cross-referenced with Google blog announcements and Epoch AI.
- **Meta AI Blog** provides announcement dates for Llama models. The Llama 4 blog post is dated April 5, 2025.
- For models with combined entries (e.g. "o3 / o4-mini"), the date reflects the joint announcement date from the changelog.

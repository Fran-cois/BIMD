$ Archéologie logicielle de l'ère IA 👴

bimd analyse votre dépôt Git, identifie l'ère LLM de votre premier commit, et fait râler un vieux dev de l'IA pour vous rappeler à quel point la vie était dure « back in my day ».

▶ Installer 🎬 Voir la démo ★ GitHub

📦 Installation

# Installation depuis PyPI
$ pip install backinmyday

# Vérification
$ bimd --help

🎬 Démo en vidéo

Vidéo générée automatiquement par demodsl — un DSL pour automatiser des démos produit à partir d'un YAML.

▸ Pour la regénérer : demodsl run docs/demo.yaml

⚙️ Les 3 commandes

bimd scan [PATH]

Analyse le dépôt Git, trouve la date du premier commit, et affiche l'ère IA correspondante avec un commentaire sarcastique.

$ bimd scan .
  📅  Date analysée : 2023-04-12
  🏷️   Ère détectée  : La Révolution GPT-4
  🤖  Modèles        : GPT-4, Claude 1, Llama 1, PaLM 2
  📏  Contexte       : 8k - 32k tokens

  👴  « On passait nos journées à écrire des prompts de 4 pages
        pour forcer le modèle à cracher du JSON valide. »

bimd era <DATE | COMMIT>

Recherche ponctuelle pour une date arbitraire ou un hash de commit.

$ bimd era 2020-07-01
  🏷️   Ère détectée  : L'Aube du Prompt
  🤖  Modèles        : GPT-3 (davinci), Codex, PaLM, DALL-E
  📏  Contexte       : 2048 - 4096 tokens

$ bimd era a1b2c3d --path .

bimd badge

Génère un badge Markdown Shields.io à coller dans votre README.

$ bimd badge .
  ![BackInMyDay Era](https://img.shields.io/badge/Era-GPT--4%20Early%20Adopter-blue)
